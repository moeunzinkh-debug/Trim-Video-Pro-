# ការកែបញ្ហា និងរបៀបប្រើ

## ១. បញ្ចូលវីដេអូ (Merge)

បញ្ហាក្នុងរូបភាពកើតពីការបញ្ចូលដោយចម្លងបទវីដេអូផ្ទាល់៖ វាតម្រូវឲ្យកូឌិក ទំហំ ទិស និងសំឡេងដូចគ្នា។

ឥឡូវកម្មវិធីព្យាយាមបញ្ចូលដោយមិនបម្លែងជាមុន។ ប្រសិនបើឯកសារមិនត្រូវគ្នា វាបម្លែងស្វ័យប្រវត្តិទៅ **H.264 + AAC** និងទំហំរួមរហូតដល់ **720p** ដោយប្រើកូឌិកក្នុងទូរសព្ទ។ ទំហំរួមយោងតាមសមាមាត្រវីដេអូដំបូង។ វីដេអូផ្សេងសមាមាត្រមានគែមខ្មៅ ដោយមិនទាញរូបឲ្យខូច។ វីដេអូគ្មានសំឡេងនឹងមានភាពស្ងាត់នៅកន្លែងនោះ។

ការបម្លែងអាចចំណាយពេល និងប្រើថ្ម/ទំហំផ្ទុក ហើយគុណភាពអាចប្រែប្រួល។ វីដេអូខូច វីដេអូមាន DRM ឬកូឌិកដែលទូរសព្ទមិនគាំទ្រ នៅតែអាចបរាជ័យ។ ឯកសារដើមមិនត្រូវបានផ្លាស់ប្តូរ។

## ២. APK Release និង Security alert

Release មុនគឺ **unsigned** ដូច្នេះមិនអាចដំឡើងបាន។ តាមជម្រើសរបស់អ្នក Release ថ្មីសម្រាប់សាកល្បងត្រូវបានចុះហត្ថលេខាដោយ **Android debug key** ហើយ CI ពិនិត្យហត្ថលេខាដោយ `apksigner`។

- ឈ្មោះកម្មវិធី៖ **Trim Video Pro (Test)**។
- Package៖ `com.aistudio.trimvideopro.moenuo.test` ដើម្បីអាចដំឡើងជាមួយកម្មវិធីចាស់។
- នេះជាកំណែសាកល្បង **មិនមែនសម្រាប់បោះពុម្ពទៅ Play Store**។
- CI រក្សាទុក test key ក្នុង cache សម្រាប់ build បន្ទាប់។ Cache មិនមែនជាកន្លែងបម្រុងទុក release key ផ្លូវការទេ។ បើ cache បាត់ ហត្ថលេខាអាចផ្លាស់ប្តូរ ហើយការដំឡើងអាប់ដេតលើកំណែ test ចាស់អាចមិនបាន។
- ការចុះហត្ថលេខាមិនអាចធានាលុបការព្រមានពី **Google Play Protect** បានទេ។ កុំបិទប្រព័ន្ធការពារដើម្បីដោះស្រាយបញ្ហានេះ។ បើនៅមានការព្រមាន សូមផ្ញើរូបភាព និងអត្ថបទព្រមានពេញលេញ ដើម្បីកំណត់មូលហេតុត្រឹមត្រូវ។

## ៣. Transcript សម្រាប់ឯកសារធំ

1. បញ្ចូល Groq API key ក្នុង Settings ហើយជ្រើស **Groq · Whisper Large v3**។
2. ជ្រើសឯកសារសំឡេង ឬវីដេអូ។ **Auto-detect** ជាលំនាំដើមសម្រាប់ភាសាដើមជាង 90។
3. កម្មវិធីអានតែបទសំឡេងដំបូង ហើយបម្លែងទៅ **16 kHz mono WAV**។ មិនផ្ញើរូបភាពវីដេអូទៅ Groq ទេ។
4. កម្មវិធីប្រើ **energy-based VAD** ដើម្បីរកចំណុចស្ងាត់សម្រាប់បំបែកចន្លោះប្រហែល 7–8 នាទី។ នេះមិនមែនជា neural VAD ឬការលុបសំឡេងរំខានដោយ AI ទេ។ ប្រសិនបើមិនមានចំណុចស្ងាត់ វាបំបែកត្រឹមកម្រិត 8 នាទី។
5. ផ្នែកនីមួយៗមានប្រហែលអតិបរមា 15.4 MB ដូច្នេះតូចជាងកម្រិត 25 MB របស់ Groq។ កម្មវិធីផ្ញើម្តងមួយៗ និងបន្តរហូតចប់។
6. ពេលវេលាអត្ថបទត្រូវបានបូកត្រឡប់ទៅពេលវេលាឯកសារដើម ដើម្បីនាំចេញ subtitle។ ភាពស្ងាត់ក្នុងឯកសារមិនត្រូវបានកាត់ចេញពីខ្សែពេលវេលាទេ។
7. កំហុសបណ្ដោះអាសន្ន និង rate limit ត្រូវបានព្យាយាមឡើងវិញរហូតដល់ 3 ដង។ បើផ្នែកមួយនៅតែបរាជ័យ អត្ថបទពីផ្នែកដែលបានសម្រេចរួចនៅតែអាចនាំចេញបាន។ កម្មវិធីមិនទាន់បន្តពីចំណុចចាស់ដោយស្វ័យប្រវត្តិ បន្ទាប់ពីបិទកម្មវិធី ឬចាប់ផ្តើមការងារឡើងវិញទេ។

ត្រូវការអ៊ីនធឺណិត ទំហំផ្ទុកបណ្ដោះអាសន្ន និង quota API គ្រប់គ្រាន់។ ឯកសារសំឡេងបណ្ដោះអាសន្នត្រូវបានលុបពេលសម្រេច ឬបោះបង់ការងារ។

## ៤. រកឯកសារ SRT / TXT / VTT

ក្រោយបង្កើតអត្ថបទ ចុចនាំចេញជា **SRT**, **TXT** ឬ **VTT**។ ទីតាំងរក្សាទុក៖

`Downloads/TrimVideoPro/Transcripts/`

បើក **Files → Downloads → TrimVideoPro → Transcripts**។ ឈ្មោះឯកសារចាប់ផ្តើមដោយ `transcript_` និងបញ្ចប់ដោយ `.srt`, `.txt` ឬ `.vtt`។ អត្ថបទខ្មែរត្រូវបានរក្សាទុកជា UTF-8។

លើ Android 7–9 សូមអនុញ្ញាតសិទ្ធិផ្ទុកពេលកម្មវិធីស្នើ។ លើ Android 10 ឡើងទៅ មិនត្រូវការសិទ្ធិផ្ទុកទូទៅសម្រាប់ការនាំចេញនេះទេ។ កម្មវិធីបង្ហាញថាបានរក្សាទុក លុះត្រាតែឯកសារពិតជាបានសរសេរទៅ Downloads ដោយជោគជ័យ។ ប្រសិនបើទំហំផ្ទុកមិនគ្រប់ ឬសិទ្ធិមិនបានអនុញ្ញាត វាបង្ហាញកំហុស មិនបង្ហាញជោគជ័យខុសទេ។

## ៥. កំហុស `Unexpected char 0x0a ... Authorization value`

`0x0a` គឺតួអក្សរចុះបន្ទាត់ដែលជាប់មកក្នុង API key ពេលចម្លង។ កំហុសនេះកើតមុនការផ្ញើទៅ Groq មិនមែនជាកំហុសទំហំវីដេអូ ឬ VAD ទេ។

ចាប់ពីកំណែ 1.1.1 កម្មវិធីដកចន្លោះ បន្ទាត់ថ្មី tab និងតួអក្សរលាក់ដែលជាប់មកពីការចម្លង ដោយស្វ័យប្រវត្តិ។ វាក៏ទទួលសោដែលមានសញ្ញាសម្រង់ជុំវិញ ឬពាក្យ `Bearer` ពីមុខ។ សោដែលបានរក្សាទុកក្នុងកំណែចាស់ត្រូវបានសម្អាតពេលអាន ដូច្នេះជាទូទៅអ្នកអាចអាប់ដេត រួចចុច Generate Transcript ឡើងវិញបាន។

បើនៅបង្ហាញថាសោមិនត្រឹមត្រូវ សូមបើក **Settings → Groq API** ហើយបញ្ចូលតែ Groq key ដែលចាប់ផ្តើមដោយ `gsk_` រួចចុច Save។ កុំបញ្ចូលឈ្មោះសោ ពាក្យពន្យល់ ឬ command ទាំងមូល។ **កុំផ្ញើ API key ក្នុង chat ឬរូបភាព។**

ការពិនិត្យសោធ្វើឡើងមុនទាញសំឡេង និងមុនបង្កើត Authorization header។ សារកំហុសនឹងមិនបង្ហាញតម្លៃសោទេ។ ការសម្អាតនេះមិនអាចជួសជុលសោដែលផុតសុពលភាព ឬត្រូវបានដកហូតទេ; សោបែបនោះអាចទទួល HTTP 401/403 ពី Groq ហើយត្រូវជំនួសនៅក្នុង Settings។
